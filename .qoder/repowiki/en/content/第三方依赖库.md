## 第三方依赖概述

MySQL Server 在 `extra/` 目录中集成了 25+ 个第三方库，提供构建所需的基础功能。这些库通常以内嵌源码的方式打包，确保构建的可重复性和版本一致性：

## 核心库

### Boost

| 属性 | 说明 |
|------|------|
| 用途 | C++ 基础库 — 几何计算、正则表达式、文件系统 |
| 使用模块 | GIS 空间计算、JSON Schema 验证、配置解析 |
| 版本要求 | 1.77+（CMake 自动检测） |

Boost.Geometry 是 MySQL GIS 子系统的数学基础，提供精确的空间计算能力。

### OpenSSL / wolfSSL

| 属性 | 说明 |
|------|------|
| 用途 | TLS/SSL 加密通信、密码哈希 |
| 使用模块 | 网络层 TLS、认证插件、加密函数 |
| CMake 选项 | `-DWITH_SSL=system` 或 `-DWITH_SSL=bundled` |

MySQL 默认使用系统 OpenSSL，也可使用捆绑的 wolfSSL。

### RapidJSON

| 属性 | 说明 |
|------|------|
| 用途 | 高性能 JSON 解析和序列化 |
| 使用模块 | JSON 子系统、X Protocol、审计日志 |
| 特点 | 仅头文件库（header-only） |

**Sources** · [extra/boost/](file://extra/boost/) · [extra/rapidjson/](file://extra/rapidjson/)

## 压缩库

MySQL 在多个场景中使用压缩：

| 库 | 目录 | 用途 |
|----|------|------|
| **zlib** | `extra/zlib/` | 网络协议压缩、binlog 压缩、表压缩 |
| **zstd** | `extra/zstd/` | 高效压缩（binlog compression、page compression） |
| **lz4** | `extra/lz4/` | 快速压缩（InnoDB 页压缩） |

### 压缩场景

| 场景 | 库 | 说明 |
|------|-----|------|
| 二进制日志压缩 | zstd | `binlog_transaction_compression` |
| InnoDB 页压缩 | lz4 / zlib | `KEY_BLOCK_SIZE` 表选项 |
| 网络协议压缩 | zlib | 客户端-服务器数据压缩 |
| 备份压缩 | zstd / lz4 | MySQL Enterprise Backup |

```sql
-- 启用 binlog 压缩
SET GLOBAL binlog_transaction_compression = ON;
SET GLOBAL binlog_transaction_compression_level_zstd = 3;

-- InnoDB 表压缩
CREATE TABLE compressed_table (
  id INT PRIMARY KEY,
  data TEXT
) ENGINE=InnoDB KEY_BLOCK_SIZE=8;
```

## 构建配置

### 系统库 vs 捆绑库

```bash
# 使用系统库（推荐，减小包大小）
cmake .. \
  -DWITH_SSL=system \
  -DWITH_ZLIB=system \
  -DWITH_LZ4=system \
  -DWITH_ZSTD=system \
  -DWITH_CURL=system

# 使用捆绑库（确保兼容性）
cmake .. \
  -DWITH_SSL=bundled \
  -DWITH_ZLIB=bundled \
  -DWITH_LZ4=bundled \
  -DWITH_ZSTD=bundled

# 混合模式
cmake .. \
  -DWITH_SSL=system \
  -DWITH_ZLIB=bundled  # 特定版本要求
```
