## 服务器生命周期概述

MySQL 服务器的完整生命周期由 `mysqld.cc`（~567KB，整个项目中最大的文件之一）管理。这个文件包含了服务器的主函数 `mysqld_main()` 以及大量的全局变量定义：

```mermaid
graph TB
    MAIN[mysqld_main — 入口]
    MAIN --> PARSE[解析参数]
    MAIN --> INIT[初始化子系统]
    MAIN --> LISTEN[启动监听]
    MAIN --> RUN[运行循环]
    MAIN --> SHUTDOWN[关闭]
    MAIN --> CLEANUP[清理]
```

**Sources** · [sql/mysqld.cc](file://sql/mysqld.cc)

## 启动阶段

### 命令行参数解析

```mermaid
graph TB
    ARGS[命令行参数 + my.cnf]
    ARGS --> PARSE[my_getopt — 参数解析]
    PARSE --> EARLY[早期参数 — datadir, basedir]
    EARLY --> CONFIG[加载配置文件]
    CONFIG --> OVERRIDE[命令行覆盖配置]
    OVERRIDE --> VALIDATE[参数验证]
```

### 启动命令

```bash
# 标准启动
mysqld --defaults-file=/etc/my.cnf &

# 初始化数据目录（首次安装）
mysqld --initialize-insecure --datadir=/var/lib/mysql

# 升级模式
mysqld --upgrade=FORCE

# 安全模式（跳过权限和网络）
mysqld --skip-grant-tables --skip-networking
```

## 初始化子系统

启动参数解析后，服务器按特定顺序初始化各个子系统：

### 初始化顺序

```mermaid
graph TB
    INIT_START[开始初始化]
    INIT_START --> MYINIT[1. mysys 基础库初始化]
    MYINIT --> CHARSET[2. 字符集系统初始化]
    CHARSET --> PLUGIN[3. 插件系统初始化]
    PLUGIN --> DD[4. 数据字典初始化]
    DD --> INNODB[5. InnoDB 存储引擎初始化]
    INNODB --> BINLOG[6. 二进制日志初始化]
    BINLOG --> ACL[7. 权限系统初始化]
    ACL --> PFS[8. Performance Schema 初始化]
    PFS --> NETWORK[9. 网络监听初始化]
    NETWORK --> THREADS[10. 后台线程启动]
    THREADS --> READY[服务器就绪 — 接受连接]
```

### 关键初始化步骤

| 步骤 | 说明 |
|------|------|
| **mysys** | 内存管理、文件 I/O、线程基础设施 |
| **字符集** | 加载字符集定义和排序规则 |
| **插件** | 加载和初始化所有已安装插件 |
| **数据字典** | 打开或创建 DD 表空间 |
| **InnoDB** | 缓冲池、重做日志、崩溃恢复 |
| **二进制日志** | 打开或创建 binlog 文件 |
| **ACL** | 加载用户和权限信息 |
| **网络** | 绑定端口和套接字 |
| **后台线程** | InnoDB page cleaner、purge、checkpoint 等 |

## 运行阶段

服务器初始化完成后进入运行循环，处理客户端连接和查询：

### 运行循环

```mermaid
graph TB
    LISTEN[监听线程 — 接受连接]
    LISTEN --> ASSIGN[分配连接处理器]
    ASSIGN --> THREAD[创建/复用 THD 线程]
    THREAD --> HANDSHAKE[协议握手]
    HANDSHAKE --> AUTH[认证]
    AUTH --> CMD_LOOP[命令循环]
    CMD_LOOP --> DISPATCH{命令类型}
    DISPATCH --> QUERY[COM_QUERY — SQL]
    DISPATCH --> PREPARE[COM_STMT_PREPARE]
    DISPATCH --> EXECUTE[COM_STMT_EXECUTE]
    DISPATCH --> QUIT[COM_QUIT — 断开]
    QUERY --> CMD_LOOP
    PREPARE --> CMD_LOOP
    EXECUTE --> CMD_LOOP
```

### 全局状态

`mysqld.cc` 定义了大量全局变量来维护服务器状态：

| 变量 | 说明 |
|------|------|
| `mysqld_port` | 监听端口 |
| `mysqld_unix_port` | Unix Socket 路径 |
| `connection_count` | 当前连接数 |
| `max_connections` | 最大连接数 |
| `server_running` | 服务器运行标志 |
| `shutdown_requested` | 关闭请求标志 |
| `abort_loop` | 中止标志 |

## 关闭流程

MySQL 支持多种关闭方式，每种方式有不同的行为：

### 关闭类型

| 方式 | 命令 | 行为 |
|------|------|------|
| **正常关闭** | `mysqladmin shutdown` | 等待所有连接完成后关闭 |
| **快速关闭** | `SHUTDOWN` + SIGNAL | 断开连接后立即关闭 |
| **中止关闭** | `kill -9` | 立即终止（需要崩溃恢复） |

### 正常关闭流程

```mermaid
graph TB
    SHUTDOWN[收到关闭请求]
    SHUTDOWN --> STOP_ACCEPT[停止接受新连接]
    STOP_ACCEPT --> KILL_CONN[关闭现有连接]
    KILL_CONN --> FLUSH[刷新缓冲和日志]
    FLUSH --> CLOSE_BINLOG[关闭二进制日志]
    CLOSE_BINLOG --> CLOSE_INNODB[关闭 InnoDB]
    CLOSE_INNODB --> CLOSE_DD[关闭数据字典]
    CLOSE_DD --> CLOSE_PLUGIN[卸载插件]
    CLOSE_PLUGIN --> CLEANUP[释放资源]
    CLEANUP --> EXIT[退出进程]
```

### 关闭 SQL

```sql
-- 通过 SQL 关闭
SHUTDOWN;

-- 等待关闭完成
-- mysqladmin --wait=30 shutdown
```

## 信号处理

`signal_handler.cc`（~15KB）处理操作系统信号：

### 信号映射

| 信号 | 说明 | MySQL 行为 |
|------|------|-----------|
| `SIGTERM` | 终止信号 | 正常关闭 |
| `SIGINT` | 中断信号（Ctrl+C） | 正常关闭 |
| `SIGHUP` | 挂起信号 | 刷新日志和重新加载权限 |
| `SIGSEGV` | 段错误 | 生成崩溃堆栈并退出 |
| `SIGABRT` | 中止信号 | 生成核心转储 |

### SIGHUP 处理

```mermaid
graph TB
    SIGHUP[收到 SIGHUP]
    SIGHUP --> FLUSH_LOGS[刷新日志文件]
    FLUSH_LOGS --> RELOAD_ACL[重新加载权限表]
    RELOAD_ACL --> RELOAD_CONFIG[重新加载配置]
    RELOAD_CONFIG --> CONTINUE[继续运行]
```

```bash
# 发送 SIGHUP 刷新日志
kill -HUP $(pidof mysqld)
# 等价于: mysqladmin flush-logs
```

## 守护进程模式

`mysqld_daemon.cc`（~4KB）实现 Unix 守护进程功能：

### 守护进程化

```mermaid
graph TB
    START[启动 mysqld]
    START --> DAEMON{--daemonize?}
    DAEMON --> |是| FORK[fork 子进程]
    FORK --> DETACH[脱离终端 — setsid]
    DETACH --> REDIRECT[重定向标准输出]
    REDIRECT --> WRITE_PID[写入 PID 文件]
    WRITE_PID --> RUN[运行服务器]
    DAEMON --> |否| RUN
```

```bash
# 守护进程模式启动
mysqld --daemonize --pid-file=/var/run/mysqld/mysqld.pid

# 检查 PID 文件
cat /var/run/mysqld/mysqld.pid
```
