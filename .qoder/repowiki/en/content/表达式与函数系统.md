## 表达式系统概述

MySQL 的表达式系统基于 `Item` 类层次结构，19 个 `item_*.cc` 文件总计约 2MB，构成了 MySQL 中最大的子系统：

| 文件 | 大小 | 说明 |
|------|------|------|
| `item_func.cc` | ~326KB | 通用函数 — 数学、信息函数等 |
| `item_cmpfunc.cc` | ~288KB | 比较函数 — =, <, >, IN, BETWEEN, LIKE |
| `item_geofunc.cc` | ~232KB | 空间函数 — ST_Distance, ST_Contains 等 |
| `item_sum.cc` | ~214KB | 聚合函数 — SUM, COUNT, AVG, MIN, MAX |
| `item_strfunc.cc` | ~180KB | 字符串函数 — CONCAT, SUBSTRING 等 |
| `item_json_func.cc` | ~169KB | JSON 函数 — JSON_EXTRACT, JSON_OBJECT 等 |
| `item_subselect.cc` | ~143KB | 子查询表达式 |
| `item_timefunc.cc` | ~135KB | 日期/时间函数 |

## Item 类层次结构

`Item` 是所有表达式的基类，形成了一个庞大的类层次：

```mermaid
graph TB
    ITEM[Item — 基类]
    ITEM --> FIELD[Item_field — 列引用]
    ITEM --> INT[Item_int — 整数常量]
    ITEM --> STRING[Item_string — 字符串常量]
    ITEM --> NULL[Item_null — NULL 常量]
    ITEM --> FUNC[Item_func — 函数调用]
    ITEM --> SUM[Item_sum — 聚合函数]
    ITEM --> REF[Item_ref — 引用]
    ITEM --> SUBSELECT[Item_subselect — 子查询]
    ITEM --> PARAM[Item_param — 预处理参数]
    ITEM --> ROW[Item_row — 行表达式]

    FUNC --> CMPFUNC[Item_func_eq — 等号]
    FUNC --> STRFUNC[Item_func_concat — CONCAT]
    FUNC --> MATH[Item_func_plus — 加法]
    FUNC --> TIMEFUNC[Item_func_now — NOW]
    FUNC --> JSONFUNC[Item_func_json_extract — JSON_EXTRACT]
    FUNC --> GIS[Item_func_srid — ST_SRID]
```

### 核心接口

| 方法 | 说明 |
|------|------|
| `val_int()` | 返回整数值 |
| `val_real()` | 返回浮点值 |
| `val_str()` | 返回字符串值 |
| `val_decimal()` | 返回 DECIMAL 值 |
| `val_json()` | 返回 JSON 值 |
| `resolve_type()` | 类型推导 |
| `fix_fields()` | 字段解析和类型检查 |
| `print()` | 打印表达式（用于 EXPLAIN） |
